## Holistic re-examination (brainstorm)

Khác biệt với walkthrough SF-2/3/4 (isolate dev stack :3100/:4101/:4102): SF-5 đi trên **compose prod-build** (10 container) — đúng điều kiện CI convergence + đúng cái người copy boilerplate sẽ chạy. Kill-remote ở chế độ này = stop container remote (nginx proxy 502 → RemoteSlot error fallback), không phải kill dev server.
