## 3. A11y

- WAI-ARIA sweep interactive (2026-10-18): **Tabs** roving tabindex + ←/→/Home/End + `aria-controls/labelledby` · **Modal/Drawer/Popconfirm/Popover** `role=dialog` + `aria-modal` + `aria-labelledby` (đủ cả title ReactNode) · **Dropdown/Menu** trigger `aria-haspopup=menu` + `aria-expanded` · **RadioGroup** name chung (arrow-key native) + accessible name · **Select** clear × operable bằng Enter/Space · **TreeTable** `role=treegrid` + `aria-level/expanded/selected`
- Chuỗi `1a086a8`: Tooltip `aria-describedby` · Popconfirm `aria-haspopup=dialog` + `aria-expanded` · ContextMenu ArrowUp/Down/Home/End + `aria-disabled` · Tree `role=treeitem/group` · Steps `aria-current="step"` · TabMenu `aria-current="page"` · focus-ring sweep Pagination/Inplace/PanelMenu/Segmented/ToggleButton
