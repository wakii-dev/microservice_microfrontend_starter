# Wakii UI Kit

Design system của bộ task-management boilerplate — **90+ React components, 0 deps runtime**, consumed qua source (ADR-0009). Look nghiêng antd, dark theme và motion dùng chung một hệ token.

## Triết lý

**Token-first.** Không màu/độ trễ/góc bo cứng trong component — mọi thứ đọc CSS var (`--accent`, `--motion-fast`, `--shadow-pop`…). Đổi token là đổi toàn hệ thống; dark theme tự cascade qua `data-bp-theme="dark"` (bật bằng nút **Theme** trên toolbar phía trên).

**Motion-first.** Chỉ animate `transform`/`opacity` trên GPU, thời lượng từ thang `--motion-instant → slow` và easing `--ease-enter/exit/toggle`. Keyframe dùng chung `bp-*`; component chuyển động (`Parallax`, `Reveal`, `CountUp` — nhóm **Motion**) tự tắt khi `prefers-reduced-motion`.

**A11y-first.** Focus ring chuẩn trên mọi control, `role`/`aria-*` wired sẵn (menu, switch, dialog, slider…), icon-only bắt buộc nhãn. Rules đầy đủ trong AGENTS.md — vi phạm là review fail.
